# Course Syllabi

Generated from the course definitions in the platform (`src/cert_*.js`). Language of instruction: **Spanish**. Delivery method: **100 % eLearning (self-paced)**, with optional immersive 3D practice on Meta Quest headsets.

All courses use the same assessment design: knowledge checks with remediation in every module, a final written assessment drawn at random from a secured bank, and a minimum passing grade of **75 %**.

| Course code (provider) | DIT-RA |
| Title (Spanish) | Operaciones del obrero de patio en taladros de tierra |
